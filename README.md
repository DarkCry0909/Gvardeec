# Гвардеец

**Гвардеец** — Android-приложение для учёта сотрудников частного охранного предприятия (ЧОП)
и контроля сроков их документов. Разработано в рамках выпускной квалификационной работы
«Разработка информационной системы учёта деятельности и ведения личных карточек сотрудников охранного предприятия».

## Возможности

- **Календарь сроков** — календарь текущего месяца с подсветкой дней, когда нужно что-то сдать или продлить; под ним список событий по датам.
- **Реестр** — разделы: Предприятия, Адреса, Документы, Сотрудники, Охр. объекты, КХО (СС), Оружие (СС), Учредители.
- **Личные карточки сотрудников** — паспорт, лицензия охранника, квалификационный разряд, медицинская справка, периодическая проверка; справка на оружие — для 6 разряда.
- **Автоматические напоминания** (уведомление ежедневно в 09:00 и отметки в календаре):

| Документ | Напоминание |
|---|---|
| Периодическая проверка | за 2 месяца и за 1,5 месяца до окончания срока |
| Лицензия охранника | за 5 месяцев и за 3,5 месяца |
| Медицинская справка | за 2 недели |
| Справка на оружие | за 2 недели |

В день окончания срока в календаре ставится отдельная отметка.
Данные хранятся локально на устройстве, подключение к интернету не требуется.

## Технологии

Kotlin · Jetpack Compose (Material 3) · Room (SQLite) · WorkManager · Gradle (Kotlin DSL) · GitHub Actions

Минимальная версия Android — 8.0 (API 26).

## Сборка APK

### Через GitHub Actions (без установки Android Studio)
1. Загрузите проект в репозиторий GitHub (вместе с папкой `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (запускается и автоматически при push в `main`).
3. Дождитесь зелёной галочки, откройте запуск и скачайте артефакт **Gvardeec-apk** — внутри файл `app-debug.apk`.
4. Скопируйте APK на смартфон и установите (разрешите установку из неизвестных источников).

### Локально
Откройте проект в Android Studio (Koala и новее) → **Build → Build APK(s)**.
Либо в терминале: `gradle assembleDebug`, файл появится в `app/build/outputs/apk/debug/`.

## Структура проекта

```
app/src/main/java/com/example/guardhr/
├── Data.kt        — сущности и база данных Room
├── Logic.kt       — типы документов, правила напоминаний, построение событий
├── Reminders.kt   — ежедневная проверка (WorkManager) и уведомления
├── Ui.kt          — экраны: календарь, реестр, сотрудники
└── MainActivity.kt
```
