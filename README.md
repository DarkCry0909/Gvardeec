# Гвардеец

**Гвардеец** — Android-приложение для учёта сотрудников частного охранного предприятия (ЧОП)
и контроля сроков их документов. Разработано в рамках выпускной квалификационной работы
«Разработка информационной системы учёта деятельности и ведения личных карточек сотрудников охранного предприятия».

## Возможности

- **Календарь сроков** — календарь текущего месяца с подсветкой дней, когда нужно что-то сдать или продлить; под ним список событий по датам.
- **Реестр** — разделы: Предприятия, Адреса, Документы, Сотрудники, Охр. объекты, КХО (СС), Оружие (СС), Учредители.
- **Личные карточки сотрудников** — фамилия, имя, отчество, дата рождения, должность, телефон; документы: паспорт, лицензия охранника, квалификационный разряд, медицинская справка, периодическая проверка; справка на оружие — для 6 разряда. У каждого документа: серия, номер, кем и когда выдан, срок действия.
- **Автоматические напоминания** (уведомление ежедневно в 09:00 и отметки в календаре):

| Документ | Напоминание |
|---|---|
| Периодическая проверка | за 2 месяца и за 1,5 месяца до окончания срока |
| Лицензия охранника | за 5 месяцев и за 3,5 месяца |
| Медицинская справка | за 2 недели |
| Справка на оружие | за 2 недели |

В день окончания срока в календаре ставится отдельная отметка.
Данные хранятся локально на устройстве, подключение к интернету не требуется.

## Оформление и перенос данных

* Тема: «Как в системе», «Светлая» или «Тёмная» (вкладка «Настройки»); тёмная тема — в мягких синих тонах.
* Перенос на новое устройство: «Создать копию» → передать файл `.gvb` → на новом устройстве «Восстановить из копии».
  Можно добавить данные к уже имеющимся (совпадающие записи не дублируются) или заменить их целиком.

## Защита информации

Приложение хранит персональные данные (паспорт, медицинские справки), поэтому реализованы следующие меры:

| Мера | Реализация |
|---|---|
| Вход в приложение | PIN-код (4–8 цифр, хранится как хэш PBKDF2-SHA256 с солью) и вход по отпечатку пальца (BiometricPrompt) |
| Защита от перебора | после 5 неверных попыток вход блокируется на растущее время |
| Автоблокировка | приложение блокируется при сворачивании |
| Шифрование данных | база SQLite зашифрована SQLCipher (AES-256); ключ случайный, защищён Android Keystore |
| Уведомления | на заблокированном экране не показываются ФИО и названия документов |
| Скриншоты | запрещены (`FLAG_SECURE`), в настройках можно отключить |
| Резервная копия | файл `.gvb`, зашифрованный AES-256-GCM по паролю пользователя (PBKDF2) |

Автоматическое облачное резервное копирование Android для данных приложения исключено: ключ шифрования привязан к конкретному устройству,
поэтому восстановление выполняется через собственную зашифрованную копию (вкладка «Защита»).

## Технологии

Kotlin · Jetpack Compose (Material 3) · Room + SQLCipher · WorkManager · BiometricPrompt · Android Keystore · Gradle (Kotlin DSL) · GitHub Actions

Минимальная версия Android — 8.0 (API 26).

## Структура проекта

```
app/src/main/java/com/example/guardhr/
├── Data.kt        — сущности и зашифрованная база данных Room
├── Security.kt    — PIN, ключи Keystore, биометрия
├── SecurityUi.kt  — экран входа, вкладка «Защита», копирование
├── Backup.kt      — шифрование и импорт/экспорт резервной копии
├── Logic.kt       — типы документов, правила напоминаний, построение событий
├── Reminders.kt   — ежедневная проверка (WorkManager) и уведомления
├── Ui.kt          — экраны: календарь, реестр, сотрудники
└── MainActivity.kt
```
